# Lab 02 — Gateway Incorreto

## Cenário

Um cliente informa ao suporte técnico que está sem acesso à Internet.

## Objetivo

Identificar uma falha relacionada ao gateway configurado em um dispositivo da rede.

O diagnóstico deverá ser realizado através de testes de conectividade e análise das configurações de rede.

## Topologia

A topologia será definida durante a montagem do laboratório.

## Investigação

Este laboratório será realizado utilizando a metodologia:

**Problema → Evidência → Hipótese → Teste → Diagnóstico → Correção → Validação**
